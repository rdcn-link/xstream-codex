# 运行环境管理

[English](operator-runtimes.md)

## 浏览与选择

公开的 **Runtimes** 页面和 GET `/v1/runtimes` 列出注册环境、版本、执行器、依赖以及构建支持。源码提交选择兼容的名称和版本。依赖放在共享镜像中，从而保持单个算子程序包较小。运行环境归档从 Runtimes 下载，而非算子详情页。

## 注册环境

管理员登录 `/admin`，打开 Runtimes，提供名称、版本、描述、固定的执行镜像 ID 及其归档、支持的执行器和依赖版本，同时注册兼容的构建镜像及归档和语言。Python 构建需要匹配的 Python 版本及已安装的 SDK/依赖。Java/Scala 构建需要相应编译器、SDK 和依赖类路径。编译期间不会下载依赖。环境目录及注册归档公开可读；版本记录不可变。

记录处理可选精简 Python/Arrow 环境，Java/Scala 可选 JVM SDK 环境，需要科学计算库时使用科学 Python 环境。这些是环境选择方向，不意味着每个仓库都预装了特定版本。

## 镜像身份与归档摘要

Docker 镜像 ID 固定执行环境。归档的 SHA-256 校验下载的归档文件，两者标识不同对象，无需相同。算子程序包包含业务代码，其摘要又是另一项。

## 构建隔离

仓库在隔离 Docker 容器中执行固定构建模板。构建成功后仍保持私有，直到管理员批准。编译器要求、限制和隔离细节见[提交与审核](operator-submission_zh.md#隔离构建)，插件注册见[源码分析与构建扩展](operator-build-extensions_zh.md)。
